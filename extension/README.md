# GeoLook 采样助手（Chrome 插件）

给「无 API 引擎的人工周检」提速：题目队列一键填入（**不代发**）、答案与引用一键提取、
回传本机 GeoLook 看板直接入库为 A 级人工样本。每周半小时的手工活压到十分钟。

## 两种模式

**手动模式（默认，零风险）**：填入问题后停在输入框，回车由你按；答案生成完点「提取答案」。
提取只读取浏览器里**已经渲染的页面**，等价于手工复制粘贴，只是不会抄漏引用链接。

**自动跑队列（需你显式开启，有风险，先读完这段）**：逐题「新开会话 → 提交 → 等生成完 →
提取 → 保存」。它确实会代你点发送——这一步越过了「辅助操作」，你需要知道：

- 各家 AI 产品的服务条款通常**不允许 API 之外的自动化访问**。用它意味着你自己承担
  账号被限制的风险，请只在自己的账号、小批量（默认上限 20 题）下使用。
- **人必须在场**：侧栏关掉即停、标签页导航走即停。页面出现验证码/风控提示立刻中止并交回给你，
  连续 2 次失败也会自停。默认每题间隔 25 秒 + 随机抖动，不做高频请求。
- 商业交付、给客户跑的采样，**建议用手动模式**——慢十分钟，但没有任何合规争议。

两种模式产出的样本口径完全一致（A 级人工样本、web 终端），指标里不做区分。

## 共同边界

- **不后台采集、不定时任务**。后台脚本只有一行「点图标开侧栏」，一切动作由你在侧栏发起，
  关掉侧栏什么都不会发生。
- **数据只进本机**。唯一的网络请求目标是 `http://127.0.0.1:8765`（你自己跑的 GeoLook 看板）。
  无遥测、无远程代码、不上传任何数据到第三方。

## 安装

1. Chrome 打开 `chrome://extensions` → 右上角开「开发者模式」
2. 「加载已解压的扩展程序」→ 选择本目录（`extension/`）
3. 本机启动看板：`python3 scripts/geo.py ui`

## 在哪个浏览器环境里采（重要）

**推荐：用配套的沙箱脚本，一条命令起一个干净浏览器。**

```bash
./sandbox.sh --init      # 首次：装一次扩展进模板（只做这一次）
./sandbox.sh --check     # 自检：模板、扩展、看板是否都就位
./sandbox.sh             # 一次性沙箱：无历史无 Cookie，用完即弃
./sandbox.sh --keep      # 持久沙箱：登录态保留，必须登录的引擎用这个
```

一次性沙箱的做法是从模板复制一份，再删掉 Cookie / History / Local Storage /
Login Data 等站点数据，扩展本身与它的存储（`Local Extension Settings/`）保留——
等于每次都是一台全新浏览器，但插件已经装好。

为什么要 `--init` 手动装一次：**Chrome 137 起移除了 `--load-extension` 命令行开关**，
不能再用命令行自动装未打包扩展了。装一次进模板，后面每次沙箱都自带。

沙箱解决的是**浏览器层面的干净**——没有你的历史、Cookie、自查行为画像。
它变不出账号：必须登录的引擎（豆包 / Kimi / 元宝 / ChatGPT）在 `--keep` 持久沙箱里
**登一次长期复用**，不需要每周准备新账号；登完把各家的记忆与个性化开关关掉，
并且这个账号从不用来搜自己品牌、不点自己官网。

**无痕窗口也能用**，但有两个限制：扩展默认在无痕里不可用，要到 `chrome://extensions`
→ 该扩展「详细信息」→ 打开「允许在无痕模式下运行」；且关窗后 `chrome.storage.local`
会清空，未上传的样本会丢——随采随传。

**侧栏顶部必须如实选择「采样环境」**，它会随样本一起入库：

| 选项 | 证据等级 | 适用 |
|---|---|---|
| 一次性沙箱 | A 级 | `./sandbox.sh` 起的环境，免登录引擎最干净的选择 |
| 无痕未登录 | A 级 | 不想用脚本时的等价选择 |
| 专用采样 Profile（已登录） | A 级 | `./sandbox.sh --keep`，必须登录的引擎 |
| 个人日常账号 | **D 级 · 待复核** | 应急用；测的是「AI 对你的画像」，不能当可见性证据 |

这和「API ≠ 网页端、Web ≠ App」是同一条纪律：不同环境采的样本不该混在一起算平均。
看板样本库里每条都标着环境，混采时一眼能看出来。

## 每周流程

1. 在专用 Profile（或无痕窗口）打开目标引擎，侧栏点开插件，**先选对采样环境**
2. 「载入队列」→ 用意图分组芯片挑这轮采什么题（带 ◆ 的是买家意图组：推荐/比较/替代/价格，
   离成交最近；「只选买家意图」一键选中它们）。队列按分组分节，同一类问题连着采
3. **手动**：选题 → 「填入问题」→ 自己按回车 → 等答案生成完 → 「提取答案」→ 「保存本题」
   **自动**：确认引擎选对 → 设好间隔与上限 → 「自动跑队列」→ 留在页面上看着它跑
4. 每题**新开对话**再问下一题（自动模式会自己开）；答案没提到你的品牌也照样保存——
   「没提到」正是数据
5. 采完点「上传到 GeoLook」→ 自动入库、重算指标；连不上看板时用「导出 .md」走
   `sample-import` 兜底
6. 回看板的「样本库」页复核：机器判读用的是正则，品牌名撞词、否定语境、竞品别名都可能误判，
   在那里能逐条纠正，改完立刻重算指标

侧栏顶部的黄条是纪律检查：不在无痕窗口时会一直提醒你。

## 自测

`test/fixture.html` 是模拟聊天页（流式吐字 + 带标题的引用链接），不连任何 AI 服务，
用来在不碰真实站点的前提下验证提取器。

`test/e2e.js` 是完整闭环回归测试：用 Chrome for Testing 真实加载扩展 →
content script 自动注入 → 侧栏载入队列 → 填入问题（验证不代发）→ 提取 →
保存 → 上传 → 看板样本库确认。跑法：

```bash
python3 scripts/geo.py ui &                                   # 看板
python3 -m http.server 8614 --directory extension &           # fixture
node extension/test/e2e.js
```

改了提取器或侧栏逻辑后跑一遍，比在真实站点上试错快得多。
注意它会往当前项目写一条测试样本，跑完记得清掉当天的 `samples/` 与 `metrics/` 文件。

## 站点适配说明

提取器按「站点专用选择器 + 通用启发式取最长 → 手动选中文本」降级。各家聊天 UI 改版后
专用选择器可能失效，此时**选中答案文本再点提取**永远可用。欢迎提 PR 更新
`content.js` 里的 `ANSWER_SELECTORS`。

实测记录（2026-08）：

| 站点 | 输入框 | 发送 | 答案提取 | 备注 |
|---|---|---|---|---|
| 秘塔 metaso.cn | ✓ textarea | 回车/按钮 | ✓ markdown 容器 | **引用是角标非链接，引用数常为 0**，属站点特性 |
| 百度 chat.baidu.com | ✓ textarea | 回车 | 待实采验证 | **会重定向到 wenxin.baidu.com**（已适配） |
| 纳米 n.cn | ✓ contenteditable | 回车 | 待实采验证 | 游客可用 |
| Perplexity | ✓ `#ask-input` | 回车 | 待登录后验证 | 本区域游客提问被登录墙拦截 |
| ChatGPT | 需登录 | — | 待登录后验证 | 登录墙，用持久沙箱登录后采 |
| 豆包/Kimi/元宝/智谱 | 需登录 | — | 待登录后验证 | 同上 |

Perplexity / Gemini 网页版提取到的样本，请在侧栏右上把引擎选为对应的**网页版口径**
（若服务端未配置对应平台码则不要混入 API 平台）——API 与网页端是两个口径，不能合并。

## 权限清单及理由

| 权限 | 用途 |
|---|---|
| `sidePanel` `storage` | 侧栏界面 + 本地暂存未上传样本 |
| `tabs` | 读当前标签页域名（识别引擎）与无痕状态（纪律提醒） |
| `host_permissions: 127.0.0.1:8765` | 回传样本到你本机的看板 |
| 各引擎站点的 content script | 提取已渲染答案、填入问题文本；只在你点按钮时执行 |
