# 国内 AI 信源偏好实测榜（CN-GEO 数据集实算）

> **这份文件里的每个数字都是从 CN-GEO 数据集算出来的，不是推断。**
> 数据版本 `2.0.1`（发布 2026-07-14），187,818 条去重引用、19,190 条域名×平台记录、12 个平台终端。
> 复算方法见文末。上游数据：`geo-citation-lab/03-cn-geo-citation-dataset`。

---

## 一、先记住这三个数字（它们会改变你的资源分配）

| 结论 | 数字 |
|---|---:|
| **品牌官网类信源占全库引用** | **1.37%**（52 个域名 / 2,569 条） |
| 商业推荐与榜单类站占全库引用 | **9.1%**（仅 28 个域名 / 17,116 条） |
| 内容平台（qq/toutiao/baidu/iesdouyin 四家）占全库引用 | **16.4%** |

**读法**：在国内 AI 引用生态里，**官网只占 1.37%**。
指望"把官网做好就会被 AI 引用"是战略性误判——官网的作用是**事实源**（让 AI 描述你时口径正确），
不是**引用源**。真正被引用的是内容平台、新闻媒体和榜单站。

反过来，**28 个榜单站吃掉 9.1% 的引用，还占据最靠前的引用位置**（见第四节）。
这是国内 GEO 里性价比最高、也最常被忽略的一块。

## 三、生态割据是可量化的：各平台 Top8 集中度与自家生态占比

| 平台端 | 总引用 | 去重域名 | Top8 集中度 | 自家生态头部信源 |
|---|---:|---:|---:|---|
| 百度 AI | 5,392 | 353 | **66.2%** | baidu.com **37.7%** |
| 文心 | 2,558 | 185 | **66.8%** | baidu.com **29.0%** |
| 千问 web | 31,462 | 1,036 | 61.0% | sm.cn（阿里夸克）**19.2%** |
| 豆包 App | 27,071 | 2,283 | 54.3% | iesdouyin.com **28.1%** |
| Kimi | 4,570 | 756 | 47.9% | 无自家生态；sohu 15.8%、cnblogs 9.1% |
| 豆包 web | 28,637 | 2,701 | 46.0% | iesdouyin.com 12.0% |
| 元宝 web | 23,468 | 2,989 | 43.8% | qq.com **20.5%** |
| **DeepSeek web** | 16,789 | 2,666 | **21.8%** | **无自家生态，最分散最中立** |
| 抖音 AI | 188 | **1** | 100% | 只引 iesdouyin.com |

**实操含义**：

- **百度 AI / 文心**：两家 Top8 集中度都超过 66%，且三分之一引用来自 baidu.com。
  不做百度百科 / 百家号 / 百度知道，基本进不去。
- **豆包**：字节生态是硬门槛，App 端 iesdouyin 占 28.1%。**抖音图文/视频是豆包 App 的主入口。**
- **元宝**：qq.com 占 20.5%，微信公众号 / 腾讯新闻是唯一高效路径。
- **千问**：sm.cn（夸克/神马搜索）占 19.2% —— 这是很多人没意识到的，**优化夸克搜索的收录等于优化千问**。
- **DeepSeek**：唯一没有自家生态的，Top8 只占 21.8%，靠通用权威度竞争。
  内容质量导向的打法在 DeepSeek 上回报最高。
- **抖音 AI**：只引自家一个域名，外部内容完全进不去，**不值得单独投入**。

## 四、引用位置：谁被放在答案最前面

`average_quote_position` 越小 = 在答案里出现得越靠前 = 权重越高。样本 ≥300 的域名里排名前 15：

| 域名 | 平均位置 | 引用量 | 类型 |
|---|---:|---:|---|
| sm.cn | 5.31 | 6,501 | 搜索代理（阿里） |
| **cnpp.cn** | 6.10 | 3,429 | **榜单站** |
| xnnews.com.cn | 6.25 | 1,419 | 地方新闻 |
| askci.com（中商情报网） | 6.27 | 329 | 行业研究 |
| **maigoo.com** | 6.36 | 6,741 | **榜单站** |
| **phb123.com（排行榜123）** | 7.12 | 437 | **榜单站** |
| iimedia.cn（艾媒） | 7.27 | 379 | 行业研究 |
| uc.cn | 7.32 | 489 | 搜索代理（阿里） |
| **cnpp100.com** | 7.35 | 783 | **榜单站** |
| csdn.net | 7.53 | 321 | 技术社区 |

**榜单站霸榜**。它们不仅引用量大，还被放在答案最前面。
原因很直白：AI 回答"哪个好/有哪些/怎么选"时，最省事的做法就是抄一份现成榜单。

## 五、Web 与 App 必须分开采：Jaccard 实测

同一产品不同终端的信源集合重合度：

| 产品 | web 域名数 | App 域名数 | 交集 | **Jaccard 相似度** |
|---|---:|---:|---:|---:|
| 千问 | 1,036 | 677 | 337 | **24.5%** |
| 元宝 | 2,989 | 3,206 | 1,480 | **31.4%** |
| 豆包 | 2,701 | 2,283 | 1,600 | 47.3% |
| DeepSeek | 2,666 | 2,337 | 1,702 | 51.6% |

**千问 web 和 App 的信源只有 24.5% 重合**——用 web 端结论去推 App 端表现，四分之三是错的。
这就是"每个平台+终端单独记、单独算"不是洁癖而是必须的原因。

## 六、由此得出的国内外部信源优先级（替换掉一切主观排序）

1. **跨平台通吃层**（覆盖 11 个平台端，一次投入全平台受益）
   - 榜单/品牌库站：`maigoo.com`、`chinapp.com`、`cnpp.cn`、`phb123.com`、`cnpp100.com`
     —— **性价比最高，且大多数团队没做**
   - 内容平台：`qq.com`（公众号/腾讯新闻）、`toutiao.com`（头条号）
   - 新闻媒体：`sohu.com`、`163.com`、`sina.cn`
   - 消费决策：`smzdm.com`（什么值得买）
2. **平台生态层**（按你最在意的平台选）
   - 百度 AI / 文心 → 百度百科、百家号、百度知道
   - 豆包 → 抖音图文与视频、头条号
   - 元宝 → 微信公众号、腾讯新闻
   - 千问 → **夸克/神马搜索收录**、阿里系内容
3. **专业内容层**（技术/B2B 类产品适用）
   - `cnblogs.com`、`csdn.net`、`zhihu.com`、`zol.com.cn`、`36kr.com`
   - 行业研究：`askci.com`、`iimedia.cn`（引用位置很靠前）
4. **官网**——必做，但**不要指望它带来引用**（全库占比 1.37%）。
   它的价值是让 AI 描述你时口径正确，以及被上面那些站引用时有个可信落点。

## 七、怎么复算

```bash
# 数据（约 430KB，只需这一个 mart）
curl -sLO https://raw.githubusercontent.com/yaojingang/geo-citation-lab/main/03-cn-geo-citation-dataset/data/marts/source_visibility.parquet
curl -sLO https://raw.githubusercontent.com/yaojingang/geo-citation-lab/main/03-cn-geo-citation-dataset/data/reference/source_types.csv

python3 -m venv .venv && .venv/bin/pip install duckdb
```

```python
import duckdb
c = duckdb.connect()
c.sql("CREATE TABLE st AS SELECT * FROM read_csv_auto('source_types.csv')")
c.sql("""SELECT domain, sum(deduplicated_citation_count) cit,
                count(DISTINCT platform_code) plats
         FROM 'source_visibility.parquet'
         GROUP BY domain ORDER BY cit DESC LIMIT 25""").show()
```

字段口径：`deduplicated_citation_count` 去重引用数、`average_quote_position` 平均引用位置、
`platform_code` 见 `cn-platforms.md` 的平台表。

**边界**：CN-GEO 原始层缺完整回答、回答批次、模型版本和采集时间，
因此**来源覆盖和跨平台共识可以直接用，趋势、情感、品牌推荐率不能**。
这是一次静态快照，不是实时监控数据。
