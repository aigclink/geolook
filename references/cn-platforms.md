# 国内 AI 平台适配与信源生态

国内 GEO 和海外不是同一套打法。海外主战场是 `US + 英文 + 高 DR 域名`；
国内是**平台生态割据**——每家 AI 优先吃自己生态里的内容。

---

## 1. 平台与终端清单

CN-GEO 数据集覆盖 12 个平台终端（`platform_code / 名称 / 终端 / 生态`）：

| code | 平台 | 终端 | 生态 |
|---|---|---|---|
| `DP` / `DPA` | DeepSeek | web / mobile | 深度求索 |
| `DB` / `DOUBA` | 豆包 | web / mobile | 字节跳动 |
| `TYQW` / `TYQWA` | 千问 | web / mobile | 阿里巴巴 |
| `TXYB` / `TXYBA` | 腾讯元宝 | web / mobile | 腾讯 |
| `KIMI` | Kimi | web | 月之暗面 |
| `BDAI` | 百度 AI 搜索 | web | 百度 |
| `WXYY` | 文心 | web | 百度 |
| `DYAI` | 抖音 AI 搜索 | web | 字节跳动 |

**同一产品的 Web 和 App 必须分开采样、分开算指标。** 这不是洁癖，是实测的信源重合度：

| 产品 | web 域名 | App 域名 | **Jaccard 相似度** |
|---|---:|---:|---:|
| 千问 | 1,036 | 677 | **24.5%** |
| 元宝 | 2,989 | 3,206 | **31.4%** |
| 豆包 | 2,701 | 2,283 | 47.3% |
| DeepSeek | 2,666 | 2,337 | 51.6% |

千问 web 和 App 的信源只有 **24.5%** 重合——拿 web 端结论推 App 端表现，四分之三是错的。

## 2. 各平台的差异化打法

下表的「自家生态占比」和「Top8 集中度」是 CN-GEO 实算值，不是印象：

| 平台 | Top8 集中度 | 自家生态头部信源 | 你要准备的东西 |
|---|---:|---|---|
| **百度 AI** | **66.2%** | baidu.com **37.7%** | 百度百科、百家号、百度知道——不做基本进不去 |
| **文心** | **66.8%** | baidu.com **29.0%** | 同上 |
| **千问** | 61.0% | **sm.cn（夸克/神马）19.2%** | **优化夸克搜索收录 ≈ 优化千问**，很多人没意识到这点 |
| **豆包 App** | 54.3% | iesdouyin.com **28.1%** | **抖音图文与视频是主入口**；头条号次之 |
| **Kimi** | 47.9% | 无自家生态（sohu 15.8%、cnblogs 9.1%） | 长报告、白皮书、结构化长文；技术社区内容 |
| **豆包 web** | 46.0% | iesdouyin.com 12.0% | 同豆包 App，但外部内容机会更大 |
| **腾讯元宝** | 43.8% | qq.com **20.5%** | **公众号、腾讯新闻**——元宝几乎唯一的护城河 |
| **DeepSeek** | **21.8%** | **无自家生态，最分散最中立** | 完整论证、可追溯数字、明确边界；**内容质量导向回报最高** |
| **抖音 AI** | 100% | **只引 iesdouyin.com 一个域名** | 外部内容完全进不去，**不值得单独投入** |

读法：集中度越高的平台越封闭，越要走它的生态；集中度低的（DeepSeek）靠通用内容质量竞争。

**实操含义**：一份内容至少要出三个版本——官网权威页（长、全、带 schema）、
公众号版（面向元宝/微信搜索）、垂类社区版（面向豆包/千问）。

## 3. 信源类型优先级

**完整实测榜见 [`cn-source-ranking.md`](cn-source-ranking.md)**——那份文件里的每个数字都是从
CN-GEO 数据集（187,818 条去重引用）算出来的。这里只放最关键的三条：

| 结论 | 数字 |
|---|---:|
| 品牌官网类信源占全库引用 | **仅 1.37%** |
| 商业推荐与榜单站（仅 28 个域名） | **9.1%**，且平均引用位置最靠前 |
| 内容平台四家（qq / toutiao / baidu / iesdouyin） | **16.4%** |

**最反直觉、也最该记住的一条**：官网只占 1.37%。
"把官网做好就会被 AI 引用"是战略性误判——**官网是事实源，不是引用源**。
它的作用是让 AI 描述你时口径正确，以及被外部站引用时有个可信落点。

优先级（按实测引用量与位置排序）：

1. **跨平台通吃层**（覆盖全部 11 个平台端，一次投入全平台受益）
   - **榜单/品牌库站**：`maigoo.com`、`chinapp.com`、`cnpp.cn`、`phb123.com`
     —— 性价比最高且大多数团队漏掉了；AI 回答"哪个好/怎么选"时最爱抄现成榜单
   - 内容平台：`qq.com`（公众号/腾讯新闻）、`toutiao.com`（头条号）
   - 新闻媒体：`sohu.com`、`163.com`、`sina.cn`；消费决策：`smzdm.com`
2. **平台生态层**（见下节各平台自家生态占比）
3. **专业内容层**：`cnblogs.com`、`csdn.net`、`zhihu.com`、`zol.com.cn`、`36kr.com`；
   行业研究 `askci.com`、`iimedia.cn`（引用位置很靠前）
4. **官网**：必做，但不要指望它带引用

**纪律**：上面是行业大盘，你的行业未必一样。跑完 `sample` 后一定要看报告里的
「AI 实际引用的信源域名 Top」——**那才是你这个行业当下真实的分发地图**，以它为准。

## 4. 语言与地域

- 目标国内市场：中文简体，问题用**国内用户真实说法**（"XX 好用吗" "XX 和 YY 哪个好" "XX 多少钱"），不要翻译腔。
- 目标海外市场：英文 + 美国域名仍是绝对主战场——可识别国家里 US 占 `82.70%–86.76%`，可识别语言里英文占 `82.90%–95.07%`。
- **中文 Prompt 触发的检索强度低于英文**（跨平台实验：英文平均引用 `11.68` vs 中文 `10.41`，Google 上差距最大 `11.57 vs 7.53`）。做海外市场就老老实实做英文原生内容，别指望中文页面被翻译引用。

## 5. 采样可行性

| 平台 | 可否 API 采样 | 说明 |
|---|---|---|
| DeepSeek | ✅ `DEEPSEEK_API_KEY` | **不联网**，测参数化知识 |
| 千问 | ✅ `DASHSCOPE_API_KEY` | 走 DashScope **原生端点** + `forced_search`，能拿到真实引用来源 |
| Kimi | ✅ `MOONSHOT_API_KEY` | 默认不联网 |

> **千问的坑（实测）**：OpenAI 兼容端点 `/compatible-mode/v1` 即使传了
> `enable_search` 和 `search_options.forced_search`，响应里也**不返回 `search_info`**，
> 流式同样没有——只能拿到答案，拿不到来源。必须走原生端点
> `/api/v1/services/aigc/text-generation/generation`，才会在 `output.search_info.search_results`
> 里给出带 `site_name` 的来源列表。另外不加 `forced_search` 时模型经常直接用参数化知识作答
> （会答出"现在是 2024 年"这种），等于没联网。脚本已按这个口径实现。
| 任意 OpenAI 兼容端点 | ✅ `OPENAI_API_KEY` + `OPENAI_BASE_URL` | 自定义 |
| 豆包（方舟 API） | ✅ `ARK_API_KEY` | 见下方说明，**联网要单独开通** |
| 元宝 / 百度 AI / 文心 / 抖音 AI | ❌ | 只能网页端或 App 端采样 |

> **火山方舟的坑（实测）**：
> 1. `/chat/completions` **不支持联网**，传 `tools:[{"type":"web_search"}]` 会报
>    `MissingParameter: tools.function`。联网只能走 `/responses` 端点。
> 2. `/responses` + `web_search` 默认返回 `ToolNotOpen`——**内容插件要在控制台单独开通**
>    （console.volcengine.com/common-buy/CC_content_plugin），不是有 API Key 就能用。
> 3. 开通前后是**两套完全不同的口径**：未开通时跑的是模型参数化知识，开通后才有真实检索和引用。
>    切换的当期必须**丢弃旧样本重设基线**，不能和历史数据放在一起算趋势。
> 4. 联网后单次约 100 秒，比千问（约 9 秒）慢一个数量级，排期时要留足时间。
>
> 脚本已做自动降级：没开通就退回不联网采样并把 `search_enabled` 记成 `false`，不会中断整期。

无 API 的平台走 `sample-sheet` 导出人工采样表，或让 Claude 用浏览器工具逐条采集后 `sample-import` 回灌。
**采样频率要克制，遵守各平台服务条款，不做批量滥采、不模拟登录。**
