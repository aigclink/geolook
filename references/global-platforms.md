# 海外平台适配

海外和国内不是同一套打法。国内是**平台生态割据**（各家先吃自己生态的内容）；
海外是**权威度筛选**——高 DR 域名、英文、美国来源先拿到候选池入场券，然后拼内容质量。

---

## 1. 平台差异（跨平台实验实测）

| 指标 | ChatGPT | Google AI Overview / Gemini | Perplexity |
|---|---:|---:|---:|
| 触发联网检索率 | 98.64% | 99.67% | 100% |
| 每条 Prompt 平均引用来源数 | 6.88 | 12.06 | 16.35 |
| 单条引用平均影响力 | **0.2567** | 0.0455 | 0.0548 |

**读法**：Perplexity 引用最广但每条权重低；ChatGPT 引用最少，但单条引用的吸收深度是
Google 的 `5.64x`、Perplexity 的 `4.68x`。所以：

- 想被**深度采纳** → 优化 ChatGPT 路径：做深度定义、完整证据链、背景整合
- 想**广覆盖露出** → 优化 Perplexity 路径：一页覆盖尽量多的子问题，做综合型长页
- 想吃 **Google AI Overview** → 强化标题关键词对齐 + **明确写出来源和出处**
  （B 层实验：要求带来源的 Prompt 在 Google 上引用数 `15.90`，远高于角色型 Prompt 的 `10.40`）

三平台对来源类型都高度集中：`官网 + 新闻 + 行业垂类` 合计占
ChatGPT `87.52%`、Google `87.34%`、Perplexity `79.12%`。**别在长尾杂站上浪费预算。**

## 2. 语言与地域：海外的硬门槛

| 口径 | ChatGPT | Google | Perplexity |
|---|---:|---:|---:|
| 可识别国家中 `US` 占比 | 85.89% | 86.76% | 82.70% |
| 可识别语言中英文占比 | 95.07% | 91.98% | 82.90% |

而且**中文 Prompt 触发的检索强度本身就更低**：C 层双语对照里英文 Prompt 平均引用 `11.68`、
中文 `10.41`，Google 上差距最大（`11.57 vs 7.53`）。

**结论**：做海外必须有**英文原生内容**，不是把中文页机翻过去。
`audit` 会检查这一条——`market` 设成 `global` 或 `both` 时，抓不到英文原生页直接报 P0。

---

## 3. 权威度门槛

被引用来源的 `Final_DR` 中位数：ChatGPT `592`、Perplexity `542`、Google `526`；
`DR ≥ 500` 的占 `55.67%–68.30%`。

权威度不自动等于高影响力，但它决定你**有没有资格进候选池**。海外铺内容的优先级：

1. **官网英文站**（必须是可抓取的静态内容，且是原生英文）
2. **英文新闻媒体 / 行业垂类媒体**（TechCrunch、VentureBeat、行业垂媒等）
3. **Wikipedia**（实体消歧的地基，规则严，但一旦进去长期有效）
4. **G2 / Capterra / Product Hunt** 等评测聚合站（B2B 软件类几乎必备）
5. **Reddit / Hacker News / Stack Overflow**（社区讨论被大量引用，但**不要刷**，被识破反噬极大）
6. **GitHub / 技术文档站 / arXiv**（技术类产品的高权重信源）
7. **LinkedIn / Medium / Substack**（补充，权重一般）

同样的纪律：**铺哪里不靠拍脑袋**，看报告里「海外 AI 实际引用的信源域名 Top」。

## 4. 采样可行性

| 平台 | API 采样 | 环境变量 | 说明 |
|---|---|---|---|
| Perplexity | ✅ | `PERPLEXITY_API_KEY` | **原生联网并返回 citations**，海外采样里证据质量最好 |
| OpenAI | ✅ | `OPENAI_API_KEY`（可配 `OPENAI_BASE_URL` / `OPENAI_MODEL`） | Chat Completions 默认不联网 |
| Gemini | ✅ | `GEMINI_API_KEY`（可配 `GEMINI_MODEL`） | OpenAI 兼容端点不带 grounding |
| ChatGPT 网页版（开 Search） | ❌ | — | 只能浏览器/人工采 |
| Google AI Overview / AI Mode | ❌ | — | 只能浏览器/人工采 |
| Copilot / Claude 网页版 / Grok | ❌ | — | 只能浏览器/人工采 |

**API ≠ 网页端**：`openai` 的 API 结果反映的是模型参数化知识，
和开了 Search 的 ChatGPT 网页版是两回事。两者在报告里各占一行，绝不合并。

## 5. 双市场的执行纪律

1. **两套问题库**。中文问题打国内平台，英文问题打海外平台，脚本按 `question.market` 自动路由。
   只有品牌验证类（"X 是家什么公司"）适合标 `both`。
2. **两套内容**，不是一套翻译。英文页要按英文用户的问法组织标题和小节。
3. **指标分开算**。跨市场平均提及率没有任何解释力，报告里国内/海外各一张表。
4. **竞品清单也要分开**。国内竞品和海外竞品经常不是同一批；排名指标是相对
   `competitors` 列表算的，清单不全会**高估**你的名次。
5. **优先级不必对称**。资源有限时先打一个市场做透，再复制方法到另一个，
   两边同时铺薄内容是最差的选择。
