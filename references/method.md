# GEO 方法层：从实证数据到可执行规则

这份文件是本 skill 所有判断的依据。凡是给用户的建议，都要能追到这里的某一条。
数据来自两项公开实证研究（详见 `sources.md`），不是行业经验谈。

---

## 0. 一句话定义

**GEO = 让内容更容易被生成式引擎「检索到 → 选进引用列表 → 真正吸收进答案」。**

它不是 SEO 的改名。SEO 的终点是排名和点击；GEO 的终点是**答案里的那句话是不是按你的口径说的**。
所以 GEO 的最小单位不是页面，是**可被抽取的事实块**。

---

## 1. 三段漏斗：不要把三件事混成一件

```
提问 → ① 是否触发联网检索 → ② 哪些信源被选进引用列表 → ③ 哪些内容真的被吸收进答案
```

| 环节 | 决定因素 | 你能做的 |
|---|---|---|
| ① 触发检索 | 问题类型（时效/事实/决策类更易触发） | 选对要打的问题：模糊问题反而更少触发检索 |
| ② 选信源 | 域名权威度、站点类型、可抓取性 | 技术底座 + 发布位置（进候选池的门票） |
| ③ 吸收 | **对题性、长度、结构、证据密度** | 内容工程（拉开差距的地方） |

**关键结论：广度 ≠ 深度。** 跨平台实验里 Perplexity 每条 Prompt 平均引用 `16.35` 个来源、
Google `12.06`、ChatGPT 只有 `6.88`；但 ChatGPT 单条引用的平均影响力是 `0.2567`，
是 Google（`0.0455`）的 `5.64` 倍、Perplexity（`0.0548`）的 `4.68` 倍。
所以"被引用次数多"和"真的被采纳"要分开算指标。

## 2. 评分口径（`scripts/audit.py` 就是这张表的代码实现）

总分 100，六个维度。每条阈值都对应下面的实测数字。

### 可抓取性（15）
进不了候选池，后面全是零。

- HTTP 200；非 200（含 202/3xx）扣分
- 无 `noindex`
- **静态 HTML 里要有正文**。纯前端渲染的 SPA 对多数 AI 抓取器等于空白页——这是国内官网最常见的致命伤
- 有 canonical
- 站点级：`robots.txt` 不封 `GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot / Bytespider / Baiduspider / Google-Extended`；有 `sitemap.xml`；建议加 `/llms.txt`

### 内容长度（15）
> Top 四分位页面平均 **1,943 词**，Bottom 四分位只有 **170 词**，差 `11.4x`。
> 分段影响力：`≤100 词 = 0.0546`，`1001–3000 词 = 0.1258`，`>3000 词 = 0.1457`。

阈值：`≥1500` 满分 / `≥1000` 85% / `≥600` 60% / `≥300` 35%。
**1000 词是门槛，不是目标。** 长不是因为字多有价值，而是 AI 需要足够材料才能切出可复用片段。

### 结构规范（20）
> Top 四分位：**10.59 个标题、47.49 个段落、列表密度 0.428**；
> Bottom 四分位：0.85 / 8.34 / 0.048。

- H1 唯一
- H2 ≥ 6（目标 8–10 节）
- 段落 ≥ 25
- 列表密度 = `li / (li + p)`，目标 ≥ 0.35

### 可抽取块（25）——**最大的杠杆**
> 页面含数字 **+61.6%**、含定义 **+57.3%**、含对比 **+55.3%**、含 how-to **+41.2%** 影响力。
> 页面类型均值：定义型 `0.1531`、对比型 `0.1524`，而纯 reference 型只有 `0.0529`。
> **纯 Q&A 格式反而 −5.7%**——"排成问答样子"没有用，有没有定义/数字/结构/对题性才有用。

五块及权重：定义 6、数字事实 6、对比 5、操作步骤 5、FAQ 3。

### 权威信号（15）
可见的发布/更新日期、作者、外部引用 ≥ 3 条、JSON-LD 结构化数据。
> 被引用来源的 `Final_DR` 中位数为 `526–592`，`DR ≥ 500` 的占 `55.67%–68.30%`。
> 权威度不自动等于高影响力，但它决定你**有没有资格进候选池**。

### 对题性（10）
> `llm_relevance_score` 是影响力最强的单一预测因子，`r = 0.432`，
> 高于语义相似度 `emb_answer_cit_cosine = 0.356` 和内容质量 `llm_content_quality = 0.292`。

标题、H1、H2 要含目标问题里的实际用词。
- 弱：`AI 正在改变世界`
- 强：`AI 搜索会优先引用什么内容？基于 23,745 条引用记录的结构化分析`

## 3. 内容工程铁律

**把内容写成「证据页」，不是「观点页」。** 每个要打的问题，页面至少具备：

1. 一句可直接摘走的定义
2. 2–5 个带单位、带出处的数字
3. 一个对比块（表格最佳）
4. 一个步骤块
5. 适用边界与不适用场景（写清楚"不适合谁"反而提高可信度）

骨架示例：

```
标题：<目标问题的原话>
1. 什么是 X（一句定义 + 一段展开）
2. 关键数字（3–5 条，每条带来源和日期）
3. X vs Y（表格，同口径维度）
4. 怎么做（5 步）
5. 适用与不适用场景
6. 常见问题（3–5 条）
7. 参考来源（真实可点开）
```

## 4. 采样与归因纪律

**没有原始答案、截图/导出、采样环境记录的，不许标成"真实采样"。**

证据等级：

| 等级 | 含义 |
|---|---|
| A | 人工/浏览器真实样本，有答案原文与来源链接 |
| B | API 可复现样本（注明是否联网） |
| C | 合成演示 / 推断 |
| D | 待复核 |

口径纪律：

- **API ≠ 网页端。** DeepSeek 官方 API 不联网，测的是模型参数化知识里的品牌认知；网页端才有检索。两者分开记，绝不合并算提及率。
- **Web ≠ App。** CN-GEO 研究发现同一产品不同终端的信源集合有系统性差异。每个平台+终端单独一行。
- **每平台独立口径**，不允许用一个平台的结论代表"AI 都这么说"。
- 指标至少四层：提及率、首位率/Top3、描述准确率、引用质量（召回 + 准确）。只看提及率会严重高估效果。
- 归因默认写成"**观察相关**"。要提高置信度，必须有基线窗口、观察窗口、对照 Prompt、竞品对照和外部事件记录。
- **永远不能承诺"某平台一定会引用某页"**，只能承诺提升可发现性、可验证性、可抽取性。

## 5. 官网的真实位置：它是事实源，不是引用源

CN-GEO 实算（187,818 条去重引用）：

| 信源类别 | 占全库引用 | 域名数 |
|---|---:|---:|
| 内容平台（qq/toutiao/baidu/iesdouyin） | 16.4% | 4 |
| 综合新闻媒体 | 13.6% | 68 |
| **商业推荐与榜单站** | **9.1%** | **28** |
| **品牌官网 / 企业站** | **1.37%** | 52 |

**官网只占 1.37%。** 这是国内 GEO 里最容易被忽略、也最影响资源分配的一个数字。

它不意味着官网不重要，而是意味着官网的**职能被搞错了**：

- 官网的作用是**事实源**——让 AI 描述你时口径正确、别把你说成别的行业
- 引用来源在别处——内容平台、新闻媒体、榜单站

所以合理的资源分配是：官网做到"可抓取 + 有定义 + 有结构化数据 + 口径统一"就够了，
**剩下的力气应该花在外部信源上**。把官网从 60 分做到 90 分的边际收益，
远低于在一个榜单站上拿到一个词条。

完整榜单和各平台差异见 [`cn-source-ranking.md`](cn-source-ranking.md)。

## 6. 优先级判据

排 P0/P1/P2 时按这个顺序，别倒过来：

1. **P0 门票问题**：robots 封禁、SPA 空壳页、无 sitemap、无结构化数据、页面不可访问
2. **P0 事实错误**：AI 把品牌说错、张冠李戴、价格/资质错 → 直接改知识库和官网事实块
3. **P1 抽取块缺口**：全站缺定义/数字/对比/步骤（看 audit 的 `block_gap`）
4. **P1 高价值问题无内容承接**：问题库里商业价值高、但站内没有对应页面
5. **P1 外部信源建设**（注意是 P1 不是 P2——官网只占 1.37% 引用，见上一节）：
   按采样里 AI 实际引用的域名去铺，不要按主观印象铺；优先跨平台通吃的榜单站和内容平台
6. **P2 长尾扩量**

不要把 SEO 排名、官网流量或品牌知名度直接等同于 GEO 优先级。
不要把"官网有这个页面"等同于"AI 能准确引用"。
